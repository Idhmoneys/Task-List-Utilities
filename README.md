# 📃 Tasks List Utilites
JavaScript project for roadmap.sh

## ✨ Features
- 📂 Add New Tasks
- ✅ Completing Tasks
- 🗑️ Removing Tasks
- 🔢 Count Incomplete Task

## How to use the feature
**to add new task, type:**
``` JavaScript
tasks = addTask(tasks, '{task massage}');
```
**to complete a task, type:**
``` Javascript
tasks = completeTask(tasks, {taskId});
```
**to remove a task, type:**
``` JavaScript
tasks = removeTask(tasks, {taskId});
```
**to count uncompleted task, type:**
``` JavaScript
countIncompleteTasks(tasks);
```
